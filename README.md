Single-page demo site (`index.html`, self-contained, no build step) built for Music Cafe, Acharya College Road, Chikkabanavara, Bengaluru, as a demo for Arya's website + AI video agency.

- Live demo: https://arya123-sudo.github.io/music-cafe-demo/
- Menu items & prices in the demo are **placeholders**, clearly labelled on the page — to be replaced with the owner's confirmed menu.
- Rooftop live-music cafe on Acharya College Road; the cafe's only web presence before this demo was a Facebook page.
- Photos are royalty-free stock images, credited in the page footer.
- This is a demo website made for Music Cafe — it is not the cafe's official site, and the cafe has not been contacted yet.
